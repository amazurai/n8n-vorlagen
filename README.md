# n8n-Vorlagen von azurai

Kostenlose, getestete [n8n](https://n8n.io)-Vorlagen für kleine und mittlere Unternehmen in Deutschland, Österreich und der Schweiz. Jede Vorlage löst einen konkreten Ablauf aus einer Branche, ist kommentiert und ohne Zugangsdaten.

| Vorlage | Branche | Was sie erledigt |
|---|---|---|
| [Kundenanfragen sortieren](handwerk-anfragen/) | Handwerk (Sanitär, Heizung, Klima, Elektro) | liest Anfragen aus dem Postfach, meldet Notfälle sofort, fragt fehlende Angaben beim Kunden nach und trägt alles in eine Tabelle ein |

## So importieren Sie eine Vorlage
1. Öffnen Sie die Datei `workflow.json` der Vorlage und kopieren Sie den Inhalt.
2. Fügen Sie ihn in n8n mit Strg+V bzw. Cmd+V in einen leeren Workflow ein.
3. Folgen Sie der Anleitung in der gelben Notiz im Workflow und in der README der Vorlage.

Getestet mit n8n 2.48 (selbst gehostet). Die Vorlagen funktionieren auch in n8n Cloud.
